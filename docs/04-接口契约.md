# 接口契约

统一约定：

- 请求/响应均为 JSON；成功响应包一层 `{"data": ...}`；分页响应 `{"data": {"items": [...], "next_cursor": "..."}}`。
- 统一错误：`{"error": "描述", "code": "错误码", "fields": [{"field": "...", "message": "..."}]?}`。
- 写操作支持业务幂等键：请求头 `Idempotency-Key` 或请求体 `idempotency_key`；重放响应带 `Idempotent-Replay: true`。
- 乐观锁：启用/状态操作请求体携带 `version`（读取时返回的当前版本号），不匹配返回 `409 CONFLICT`。
- 分页：`limit`（1-200，默认 50）+ `cursor`（上一页 `next_cursor`），按 (created_at, id) 稳定排序。

## 错误码

| HTTP | code | 含义 |
| --- | --- | --- |
| 400 | VALIDATION | 参数校验失败 |
| 404 | NOT_FOUND | 资源不存在 |
| 409 | CONFLICT | 乐观锁冲突 |
| 422 | INVALID_STATE | 非法状态转换 |
| 422 | HOLD_BLOCKING | 存在未关闭暂扣 |
| 422 | STATION_SKIP | 非法越站 |
| 422 | QUALIFICATION | 资质窗口不满足 |
| 422 | CAPABILITY | 设备/腔体能力不匹配 |
| 422 | RECIPE_FAMILY | 配方与设备族不兼容 |
| 422 | WAFER_BUSY | 晶圆已在其它运行中 |
| 422 | SAMPLING | 抽样覆盖不足 |
| 422 | RUN_NOT_COMPLETED | 运行未完工 |
| 500 | INTERNAL | 内部错误 |

## 健康检查

`GET /healthz` → `{"status":"ok"}`（数据库不可达时 503）。

## 典型业务链示例

```
POST /api/v1/product-families            # 产品族建档
POST /api/v1/stations                    # 站点建档
POST /api/v1/recipes + versions + activate
POST /api/v1/metrology-plans + activate
POST /api/v1/routes + revisions + activate
POST /api/v1/equipment + chambers + /api/v1/qualifications
POST /api/v1/lots                        # 批次登记
POST /api/v1/lots/{id}/split             # 子批拆分（可选）
POST /api/v1/lots/{id}/enter             # 进站 + 冻结
POST /api/v1/runs                        # 开工
POST /api/v1/runs/{id}/complete          # 完工
POST /api/v1/runs/{id}/readings          # 量测
POST /api/v1/runs/{id}/seal              # 封存判定
POST /api/v1/lots/{id}/release-next      # 下一站放行（循环各站）
POST /api/v1/lots/{id}/close             # 末站后关闭
# 异常分支：
POST /api/v1/holds                       # 人工暂扣 / 判定失败自动暂扣
POST /api/v1/holds/{id}/review           # 复判：RELEASE / REWORK / SCRAP
```

# 数据模型

存储：嵌入式 SQLite（`modernc.org/sqlite`，纯 Go、无 cgo），`database/sql` 访问。
时间统一存 Unix 毫秒（INTEGER），JSON 存 TEXT。数据库文件由 `DB_PATH` 指定，禁止 `:memory:`。

## 表清单

### product_families 产品族
| 列 | 类型 | 说明 |
| --- | --- | --- |
| id | TEXT PK | `pf_` 前缀 |
| code | TEXT UNIQUE | 产品族编码 |
| name | TEXT | 名称 |
| created_at | INTEGER | 创建时间 |

### stations 站点
id PK（`st_`）、code UNIQUE、name、capability（要求的能力标签）、created_at。

### routes 工艺路线
id PK（`rt_`）、product_family_id FK、code UNIQUE、name、created_at。

### route_revisions 路线修订
id PK（`rr_`）、route_id FK、revision（UNIQUE(route_id, revision)）、status（DRAFT/ACTIVE/RETIRED）、rework_from_hold_id（返工来源暂扣）、reentry_seq（返工重入站点）、version（乐观锁）、created_at。

### route_stations 路线站点
id PK、route_revision_id FK、seq（UNIQUE(route_revision_id, seq)，从 1 连续）、station_id FK、recipe_id、metrology_plan_id。

### recipes 配方
id PK（`rc_`）、code UNIQUE、name、equipment_family（适配设备族）、created_at。

### recipe_versions 配方版本
id PK（`rv_`）、recipe_id FK、version（UNIQUE(recipe_id, version)）、status、params_json（草稿参数）、snapshot（启用时生成的不可变快照）、activated_at、row_version（乐观锁）、created_at。

### equipment 设备
id PK（`eq_`）、code UNIQUE、name、family（设备族）、station_id FK、status（ACTIVE/DOWN）、version、created_at。

### chambers 腔体
id PK（`ch_`）、equipment_id FK、code（UNIQUE(equipment_id, code)）、capability、status、created_at。

### qualifications 资质窗口
id PK（`qu_`）、equipment_id FK、chamber_id（空=整台设备）、station_id FK、valid_from、valid_to、status（ACTIVE/REVOKED）、created_at。

### metrology_plans 量测计划
id PK（`mp_`）、code、version（UNIQUE(code, version)）、status、sample_positions（JSON 数组，槽位）、min_samples、pass_limit（判定阈值）、metric、row_version、created_at。

### lots 批次
id PK（`lot_`）、code UNIQUE、product_family_id FK、route_id FK、status、current_seq（0=未进站）、frozen_revision_id、freeze_snapshot（冻结快照 JSON）、frozen_at、parent_lot_id（谱系）、entered_at（当前站进站时间）、version（乐观锁）、created_at、closed_at。

冻结快照 JSON 结构：
```json
{
  "route_id": "rt_...",
  "route_revision_id": "rr_...",
  "revision": 1,
  "stations": [
    {
      "seq": 1,
      "station_id": "st_...",
      "station_code": "ETCH",
      "capability": "etch",
      "recipe_id": "rc_...",
      "recipe_version_id": "rv_...",
      "recipe_snapshot": "{\"recipe_id\":\"rc_...\",\"version\":1,\"params\":{...}}",
      "metrology_plan_id": "mp_...",
      "plan_snapshot": "{...量测计划 JSON...}"
    }
  ]
}
```

### wafers 晶圆
id PK（`wf_`）、code UNIQUE、lot_id FK、slot（批内槽位）、status、created_at。

### wafer_moves 迁移记录（谱系）
id PK、wafer_id FK、from_lot_id、to_lot_id、created_at。

### runs 制程运行
id PK（`run_`）、lot_id FK、route_revision_id（冻结修订）、station_seq、station_id、equipment_id、chamber_id、recipe_version_id、recipe_snapshot（运行实际使用的快照副本）、status、judgment（NONE/PASS/FAIL）、qual_covered（完工复核结果）、reviewed（复判标记）、started_at、completed_at、version、created_at。

### run_wafers 运行晶圆
(run_id, wafer_id) 复合主键。

### readings 读数
id PK（`rd_`）、run_id FK、wafer_id、slot、metric、value、late（迟到标记）、sealed（封存标记）、created_at。

### holds 暂扣
id PK（`hd_`）、lot_id FK、run_id（可空）、reason、status、escalated（升级标记）、review_note、version、created_at、closed_at。

### rework_records 返工记录
id PK、lot_id、hold_id、new_revision_id、reentry_seq、created_at。

### releases 放行记录
id PK（`rl_`）、lot_id FK、from_seq、to_seq（0=出厂/关闭）、kind（NEXT_STATION/CLOSE/RESTORE）、note、created_at。

### audit_events 审计事件
id PK（`au_`）、entity、entity_id、action、detail（JSON）、tx_tag（同事务关联）、created_at。

### idempotency_keys 幂等键
(scope, key) 复合主键、response（首次响应 JSON）、created_at。

### jobs 后台作业
id PK（`jb_`）、kind、payload、status、attempts、max_attempts、run_at、last_error、created_at、updated_at。

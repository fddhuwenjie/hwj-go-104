# 状态转换表

本文件与 `internal/domain/states.go` 一一对应，所有状态变更必须先经过状态机校验。

| QUEUED | ON_HOLD | 人工暂扣 / 超时暂扣 |
| QUEUED | SCRAPPED | 报废 |

## 制程运行 Run

| 当前状态 | 允许目标状态 | 触发动作 |
| --- | --- | --- |
| RUNNING | COMPLETED | 完工（复核资质区间覆盖） |
| RUNNING | ABORTED | 超时运行检查作业 |
| COMPLETED | JUDGED | 量测封存与自动判定 |
| COMPLETED | ABORTED | 异常中止 |
| JUDGED | —（终态） | |
| ABORTED | —（终态） | |

判定 Judgment：NONE → PASS / FAIL（封存时确定，迟到量测不改变）。

## 暂扣 Hold

| 当前状态 | 允许目标状态 | 触发动作 |
| --- | --- | --- |
| OPEN | RELEASED | 复判放行 |
| OPEN | REWORKED | 复判返工（创建新修订） |
| OPEN | SCRAPPED | 复判报废 |
| RELEASED / REWORKED / SCRAPPED | —（终态） | 复判只允许一次 |

## 后台作业 Job

| 当前状态 | 允许目标状态 | 触发动作 |
| --- | --- | --- |
| PENDING | RUNNING | 调度器抢占（attempts+1） |
| RUNNING | DONE | 处理成功 |
| RUNNING | FAILED | 处理失败且 attempts < max |
| RUNNING | DEAD | 处理失败且 attempts ≥ max |
| FAILED | PENDING | 重试作业重新排队 |
| RUNNING（进程崩溃遗留） | PENDING | 重启恢复 |
